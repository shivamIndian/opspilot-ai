# OpsPilot AI Automation & Utility Scripts

This directory contains repository-wide maintenance, bootstrapping, and orchestration scripts.

## Planned Scripts (Modules 01 - 28)

- `bootstrap.sh` / `bootstrap.ps1`: Automated environment setup, installing Node.js dependencies and Python virtual environments via `uv`.
- `clean.sh` / `clean.ps1`: Nuclear cleanup of caches, build directories, and virtual environments.
- `verify.sh` / `verify.ps1`: One-click verification suite executing type checks, linting, and health checks across all services.
